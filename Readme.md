# Binance Trading Bot – Testnet (Python)

A simplified crypto trading bot built using Python and the Binance Futures Testnet API.

## 🚀 Features

- ✅ Market and Limit order support (Buy/Sell)
- ✅ Binance USDT-M Futures Testnet integration
- ✅ CLI-based user interaction
- ✅ Logging of API requests and errors
- ✅ Structured code for reusability
- ✅ Clean error handling
